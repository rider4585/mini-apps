# PWA

Implemented with `vite-plugin-pwa` (Workbox under the hood).

## Config (`vite.config.js`)

- `registerType: "autoUpdate"` — new builds are picked up in the background.
- `manifest`:
  - name: `DSR Mail Generator`, short_name: `DSR Mails`
  - description, `start_url: "/"`, scope `/`
  - `display: "standalone"`, `orientation: "portrait"`
  - `theme_color: "#4F46E5"`, `background_color: "#FFFFFF"`
  - icons: 192 (any), 512 (any), 512 (maskable)
- `workbox.globPatterns`: `**/*.{js,css,html,svg,png,ico}` → offline caching of the app shell.
- `includeAssets`: favicon.svg, apple-touch-icon.png, icons.

## Icons (`public/icons/`)

Generated by `scripts/generate-icons.mjs` (dependency-free PNG encoder):
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`, `favicon.svg`.
- Design: indigo→violet gradient tile with a white send/chevron mark; maskable variant is
  full-bleed (no rounded corners).

## Registration

- `src/main.jsx` imports `registerSW()` from `virtual:pwa-register`.

## Testing

- `vite dev` → app + manifest served; SW registered (devOptions enabled).
- `vite build` → `dist/` includes `manifest.webmanifest`, `sw.js`, precache manifest.
- Install from browser address bar (Chrome/Edge) or Safari "Add to Home Screen".

## Notes

- iOS Safari notifications require the PWA to be added to the home screen and to request
  permission from the browser settings.
- The service worker caches navigation + static assets so the tool works offline once loaded.
